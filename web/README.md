# web拼图游戏
> 生成一个网页端的拼图还原游戏

## 游戏玩法
1. 支持输入图片，打乱后生成拼图
2. 支持6x6、7x7、8x8三种规格对输入的图片进行等分成大小一样的矩形图像块
3. 打扰的图像块之间有明显分隔线
4. 通过拖动交换两个图像块
5. 如果两个图像块在原图中是相邻的则融合成一个整体，且相邻边的分割线消失，后面搬动其中一块时，融合后的整体一起移动效果
6. 拖动一个融合块放下时，融合块对应的位置块都发生交换，如果发生交换的块属于另一个融合块，则被分割出来交换。
7. 当发生块融合时，动画高亮一会（暂定1秒）新整合块的边框，注意融合块不一定是矩形块，可能是不规则形状（如T形等）
